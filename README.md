# 熊野古道中边路攻略

网站：https://poseidon-flechazo.github.io/kumano-kodo/

2026年12月4日至8日的中边路旅行攻略，包含每日行程、37处盖章点、去返程车票状态、43项携带清单、住宿安排、官方地图和公交时刻表。

网站入口为 `index.html`，使用 GitHub Pages 从 `main` 分支根目录发布。所有站内资源均使用相对路径，支持项目站点。

`guide.pdf` 为手机离线阅读版，`itinerary.xlsx` 为行程表。地图与公交表位于 `熊野古道_攻略附件`，图片、字体和网页样式位于 `kumano-assets`。

携带清单和车票概览的发布数据分别位于 `kumano-assets/packing-list.json` 与 `kumano-assets/transport-status.json`。装包与盖章勾选独立保存在当前浏览器。

本仓库仅包含网站发布文件。预约凭证、付款截图、乘车票和本地维护数据保存在本地，不属于发布内容。

照片来源见 `kumano-assets/image-credits.json`；字体授权文件位于 `kumano-assets/fonts`。
